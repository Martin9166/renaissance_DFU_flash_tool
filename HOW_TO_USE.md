# How to use Renaissance DFU Flash Tool

> **Warning:** The `--repartition-emmc` option recreates the eMMC UDA partition layout and overwrites existing data on every detected board. Back up important data before proceeding.

1. Set the board's boot-mode switches to USB boot (`1010`).
2. Connect the board to the host with a USB data cable.
3. Optionally, connect a serial cable between the host and the board to monitor
   console output.
4. Power on the board.
5. Open a terminal in the `DFU_flash` project directory.
6. Run the flashing command:

```bash
sudo python3 dfu_flash.py -d am62xx-evm -t hsfs \
    -c bin/am62xx-evm/hsfs/flash-three-partitions.cfg \
    --repartition-emmc
```
